# Minecraft Byggekonkurranse

## Kort beskrivelse

Dette prosjektet er en nettside for en Minecraft-byggekonkurranse for elever ved Hamar katedralskole. Nettsiden gir informasjon om konkurransen og gjør det enklere for elever å finne ut hvordan de kan delta.

## Programmeringsspråk

Nettsiden er laget med:

* HTML
* CSS
* JavaScript

## Hva gjør nettsiden?

Nettsiden inneholder informasjon om:

* Minecraft-byggekonkurransen
* Hvordan man kan delta
* Regler for konkurransen
* Praktisk informasjon
* Informasjon om arrangementet
* Vanlige spørsmål (FAQ)
* Påmelding

Nettsiden er laget med et Minecraft-inspirert design og fungerer både på PC og mobil.

## Hvordan kjøre prosjektet?

For å kjøre prosjektet lokalt:

1. Last ned eller klon prosjektet fra GitHub.
2. Åpne prosjektmappen i Visual Studio Code.
3. Finn `index.html`.
4. Åpne filen i en nettleser.

Nettsiden kan også publiseres på en webserver slik at andre kan besøke den.

## Eksempel på kode

Et eksempel fra prosjektet:

```html
<header>
    <h1>Minecraft Byggekonkurranse</h1>
    <p>Vis hva du kan bygge!</p>
</header>
```

JavaScript brukes blant annet til å gjøre nettsiden mer interaktiv og funksjonell.

## Utfordringer

Noen utfordringer jeg møtte under arbeidet var:

* Å lage et design som passer til Minecraft-temaet.
* Å få nettsiden til å fungere godt på både PC og mobil.
* Å lage en oversiktlig meny og navigasjon mellom sidene.
* Å få HTML, CSS og JavaScript til å fungere sammen.
* Å lage knapper og funksjoner som fungerer som de skal.
* Å få alle sidene til å ha et likt og gjennomført design.
